Surfshark WireGuard runs on the TV itself. Changing the country or the kill switch reconnects the VPN when it is on. Your home network, Vetro included, stays reachable; DNS goes to Surfshark and IPv6 is blocked while the VPN is on. Reconnecting needs this plugin switched on.

Private key · country switching

In a browser, go to Surfshark → VPN → Manual setup → Router → WireGuard, generate a key pair and paste its public key into the website. Paste the matching private key here. The TV then picks the least loaded server in the country you choose above, using Surfshark's public server list — no login needed. Saving a key replaces any full config below.

WireGuard config (fixed server)

In a browser, go to Surfshark → VPN → Manual setup → Router → WireGuard, generate a key pair, choose a location and download the config. Paste its whole contents here. The config is stored on the TV only and is then used instead of account login, which some networks block.
